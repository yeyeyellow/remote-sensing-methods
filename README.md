# 遥感方法资料汇总

本仓库集中提供洪水深度估算、SAR 水体提取和土壤湿度反演相关资料包。

## 下载资料

请在 [统一下载页面](https://github.com/yeyeyellow/remote-sensing-methods/releases/latest) 下载下列三个附件：

- [洪水深度估算方法汇总.zip](https://github.com/yeyeyellow/remote-sensing-methods/releases/download/v1.0.0/flood-depth-methods.zip) — 8.2 MiB
- [SAR水体提取方法汇总等三个压缩包.7z](https://github.com/yeyeyellow/remote-sensing-methods/releases/download/v1.0.0/sar-water-extraction-methods.7z) — 35.6 MiB
- [土壤湿度反演.zip](https://github.com/yeyeyellow/remote-sensing-methods/releases/download/v1.0.0/soil-moisture-inversion.zip) — 1781.3 MiB

## 解压与校验

ZIP 文件可使用系统解压工具；7z 文件请使用 7-Zip 等支持该格式的软件。

三个压缩包作为 Release 附件提供。仓库页面的 Code → Download ZIP 只包含说明文件，不包含这些附件。

SHA-256 校验值见 [SHA256SUMS.txt](SHA256SUMS.txt)。

下载附件使用英文文件名以保证兼容性，页面链接文字对应原始中文资料名。压缩包内容保持原样。
